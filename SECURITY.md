# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities in Easy Property Listings privately by email to **support@easypropertylistings.com.au**.

Do not open a public GitHub issue or post in the WordPress.org support forum for security reports.

Please include:

- The affected version.
- Steps to reproduce or a proof of concept.
- The impact you believe it has.

We will acknowledge your report, work with you on a fix, and credit you in the change log unless you prefer otherwise.

## Supported Versions

Security fixes are released for the latest version available on [WordPress.org](https://wordpress.org/plugins/easy-property-listings/).
